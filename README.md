# E-Commerce Customer Analysis

## Overview

This project analyzes customer behavior in an E-Commerce platform and applies Machine Learning techniques to predict customer spending based on customer features.

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Selection
- Machine Learning Model
- Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset

The project uses the **Ecommerce Customers** dataset.

## Results

The trained model predicts customer spending using customer-related features with good performance.
